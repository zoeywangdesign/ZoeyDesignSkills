## 1. 核心设计哲学

电商会员设计面临三重复合挑战，不可用单一视角解决：

| 维度 | 挑战 | 设计响应 |
|------|------|----------|
| **行业** | 场景高度多样化（浏览、决策、结算、售后…） | 针对各场景差异化的心智模型 |
| **商家** | 运营诉求个性化（品牌感、促销策略、适配度各异） | 兼容个性化的半开放框架 |
| **用户** | 关系阶段化（潜在→新→忠诚→流失） | 满足不同阶段的核心诉求 |

> **关键原则**：平台化的单一解决方案在会员设计中往往失效。设计师的核心任务是在"标准化效率"与"个性化适配"之间找到可维持的平衡点。

## 2. 准则一：多场景差异化认知设计

### 2.1 场景分析框架

在开始任何会员设计之前，先对目标场景做四维评估：

```
空间可用性   → 该场景能容纳多少信息？（低 / 中 / 高）
基础品牌感   → 该场景本身的品牌承载力？（弱 / 中 / 强）
信息复杂度   → 用户当前能接受的信息量？（简 / 中 / 丰富）
场景相关性   → 会员权益与当前任务的相关程度？（低 / 中 / 高）
```

根据四维评分的组合，决定该场景的引导策略与信息量级。

### 2.2 三类核心场景的设计重点

#### 浏览场景（商品列表、店铺首页、搜索结果）

- 用户处于"泛探索"状态，注意力分散
- **设计重点**：最小化干扰，仅露出会员专属价差或显著差异标签
- **禁止**：弹出完整会员介绍、展示复杂权益列表
- **推荐做法**：在价格旁直接标注「会员价 ¥XX」vs「原价 ¥XX」，让价差本身说话

#### 决策场景（商品详情页、对比页、收藏清单）

- 用户正在评估是否购买，有较高的信息接受度
- **设计重点**：聚焦本次购买的直接获益，降低决策摩擦
- **推荐做法**：「开会员，本单立省 ¥XX」配合单步入会行动点
- **注意**：避免将此场景当作完整品牌宣传的入口

#### 结算场景（购物车、下单页、支付确认）

- 用户已有强烈购买意图，是转化率最高的场景
- **设计重点**：即时利益点 + 零摩擦入会（利用渠道账号能力预填信息）
- **推荐做法**：在订单金额旁嵌入「开会员本单减 XX，立即开通」
- **禁止**：此处不应跳转至会员详情页，应原地完成入会

### 2.3 跨渠道一致性原则

- 用户体验主链路（发现 → 入会 → 使用）在各渠道保持结构一致
- 视觉语言可随渠道调整，但信息架构不应出现断层
- 跨渠道绑定时，充分利用已有账号数据，避免重复填写

## 3. 准则二：触点类型化与转化路径设计

### 3.1 四种触点类型定义

将所有会员曝光入口归类为以下四种类型，并为每种类型制定专属的引导规范：

#### A. 任务增益型

- **典型载体**：下单确认页、购物车页、配送选择页
- **用户状态**：正在执行明确任务
- **引导策略**：以"本次任务的直接增益"切入，不打断主任务流
- **核心信息**：本单可省金额 + 单步开通行动点
- **内容量级**：极简（1~2 个信息点）

#### B. 决策刺激型

- **典型载体**：商品详情页、对比页、店铺评价区
- **用户状态**：正在评估与比较
- **引导策略**：放大会员与非会员的价格/权益差异，制造对比感知
- **核心信息**：会员价 vs 普通价 + 权益概述
- **内容量级**：中等（3~5 个信息点）

#### C. 入口分发型

- **典型载体**：品牌主页、会员专区、个人中心
- **用户状态**：主动探索，有较高接受度
- **引导策略**：全貌展示会员体系，传递品牌价值主张
- **核心信息**：品牌标识 + 权益全景 + 等级体系 + 行动点
- **内容量级**：丰富（完整权益列表）

#### D. 直接消费型

- **典型载体**：商品列表价格标签、搜索结果、推荐位
- **用户状态**：被动接触，注意力极短
- **引导策略**：价格本身即是引导，无需额外话术
- **核心信息**：会员价标签（视觉突出）
- **内容量级**：极简（仅价格差异）

### 3.2 触点规范化流程

```
Step 1：识别该入口属于哪种触点类型
Step 2：按类型匹配对应的信息组合模板
Step 3：根据四维评分（空间/品牌/复杂度/相关性）微调信息量
Step 4：确认行动点的层级与跳转目标
Step 5：统一归入可复用的渠道引导规范库
```

### 3.3 入会链路设计要点

入会链路分为三段，每段有明确的设计责任：

**购前（曝光转化）**
- 目标：让用户产生"这个会员我应该了解一下"的动机
- 关键指标：曝光点击率

**购中（入会转化）**
- 目标：降低填写与决策摩擦，完成注册
- 渠道赋能：利用平台账号能力预填手机号、生日、性别等字段
- 关键指标：入会完成率

**购后（使用转化）**
- 目标：让用户在第一次消费中真实感知到权益价值
- 关键指标：首次权益使用率、30日复购率

## 4. 准则三：半开放式个性化设计框架

### 4.1 三层框架结构

面对高度分散的商家类型（品牌规模、业态、运营成熟度各异），采用三层嵌套的设计框架：

```
┌─────────────────────────────┐
│  层级三：样式定制层          │  → 品牌色、字体、图标风格
│  满足品牌个性                │    最小成本，最大品牌感知差异
├─────────────────────────────┤
│  层级二：内容灵活层          │  → 模块组合、权益类型、信息密度
│  根据运营诉求自由搭建         │    各模块零耦合，可独立增减
├─────────────────────────────┤
│  层级一：链路统一层          │  → 注册、入会、领取、使用流程
│  高效且遵循渠道平台规范       │    所有商家共用，不可随意改动
└─────────────────────────────┘
```

### 4.2 各层设计准则

#### 链路统一层（不可定制）

- 所有商家共用同一套核心交互流程
- 渠道账号能力（自动预填、授权绑定）在此层统一实现
- 链路改动需经平台级评审，不对单一商家开放

#### 内容灵活层（可配置）

- 页面由独立功能模块构成，模块间**零耦合**
- 可配置模块示例：开卡礼模块、等级进度模块、专属商品模块、储值模块、积分兑换模块
- 启用或关闭任意模块，不影响其他模块的展示与功能
- 模块排序应遵循：高转化模块优先，同类模块归组

#### 样式定制层（优先开放）

- **品牌色是性价比最高的个性化手段**：仅替换主色，即可显著改变整体品牌感知
- 定制范围建议：主色、辅色、会员卡底色、品牌 Logo
- **不建议开放**：排版结构、字号体系、间距规范、交互行为
- 开放顺序建议：先开放品牌色 → 再开放卡面图案 → 最后开放布局模板

### 4.3 模块化设计原则

```
1. 每个模块有独立的展示逻辑，不依赖其他模块的数据或状态
2. 模块高度自适应内容，不预设固定高度
3. 模块标题语言统一，格式为「动词 + 名词」（如：领取礼包 / 查看等级 / 使用优惠）
4. 空状态与加载态属于模块内部责任，不应暴露到页面层
```

## 5. 准则四：用户生命周期阶段化设计

### 5.1 三阶段核心模型

| | 潜在用户 | 活跃用户 | 忠诚用户 |
|--|--------|---------|---------|
| **核心心理** | 价值可兑现预期 | 价值已兑现印证 | 身份对比度与优越感 |
| **用户特征** | 有消费经历、有信任基础 | 喜新不厌旧、消费不稳定 | 价格不敏感、追求优越感 |
| **商家目标** | 拉新转化 | 刺激复购 | 情感增值 |
| **设计关键词** | 直观、立享、品牌认知 | 既得权益、沉没成本、成长激励 | 尊贵感、个性化、身份标识 |

### 5.2 各阶段设计重点

#### 潜在用户：建立价值预期

**页面框架设计原则**（以入会引导页为例）：

```
头部（心智对焦）
→ 强化适用范围的广泛性：「XX 门店均可使用」
→ 传递品牌感，建立信任基础

颈部（快速浏览区）
→ 权益符号化聚合：用图标 + 短标题的方式让用户快速感知权益的多样程度
→ 研究表明：权益种类 ≥3 种时，转化率显著提升

身部（权益详情区）
→ 按权益类型敏感度排序（高敏感类型优先曝光）
→ 放大数量敏感型权益的展示空间（如：优惠券数量、折扣力度）
```

**关键数据结论**：
- 配置开卡礼的门店，动销率比未配置高约 8 个百分点
- 配置满减或特价品的门店，动销率提升约 10 个百分点
- 权益类型越丰富（1→2→3 种），动销率呈梯级上升

#### 活跃用户：持续印证价值

- **周期性价值显化**：定期展示「本周期已为你节省 ¥XX」，将抽象权益转化为具体数字
- **沉没成本设计**：展示已积累的积分、已使用的次数、距离下一等级的差距
- **成长进度可视化**：等级进度条、里程碑节点、升级后的权益预览
- **禁止**：向活跃用户反复展示入会引导信息（会制造"被当成新人"的负面感受）

#### 忠诚用户：强化身份尊贵感

- **身份标识前置**：会员等级、专属徽章在个人中心显眼位置展示
- **差异化视觉**：忠诚会员的卡面、配色、图标与普通会员有明显视觉区分
- **个性化权益**：生日礼、会员日、专属客服等情感型权益，增加情感黏性
- **对比感设计**：在适当场景展示"会员专属"标签，强化身份带来的差异体验

### 5.3 流失/到期场景的特殊处理

到期用户的心理状态不同于新用户，**不应将其当作新用户重新说服**。

```
正确做法：
→ 展示「上期已为你节省 ¥XX」（激活沉没成本感知）
→ 提供续费专属优惠（比首次开卡更优惠）
→ 突出"续费立即恢复所有权益"（消除等待焦虑）

错误做法：
→ 展示完整的会员权益介绍（用户已知道，重复展示浪费信任）
→ 将续费与开卡用同一套页面（缺乏对用户历史的尊重）
```

### 5.4 券包的全场景设计原则

券包是会员使用频率最高的模块，设计目标是让用户快速找到"当前场景下可用的权益"。

```
归类维度（推荐）：「使用端 + 使用场景」
示例：饿了么外卖 / 口碑团购 / 线下买单

而非（不推荐）：
→ 按券面额排序（用户关心的是能不能用，而非金额大小）
→ 仅按有效期排序（缺乏场景关联）

体验目标：
→ 用户能回答"有哪些权益？在哪里用？怎么用？"
→ 心智打造：所有场景的权益，在这里都能找到
```

## 6. 设计决策检查清单

在提交任何会员相关设计方案前，逐项确认：

### 场景维度
- [ ] 是否识别了该入口的触点类型（任务增益 / 决策刺激 / 入口分发 / 直接消费）？
- [ ] 信息量级是否与该场景的"空间可用性 × 场景相关性"匹配？
- [ ] 是否避免在结算场景中跳转至会员详情页？

### 转化维度
- [ ] 入会引导是否清晰呈现了"立即可得"的权益（而非未来可能得到的权益）？
- [ ] 是否充分利用了渠道账号能力减少手动填写步骤？
- [ ] 权益展示是否包含至少 3 种不同类型的权益？

### 个性化框架维度
- [ ] 商家定制是否仅在样式层和内容层，未破坏链路层的统一性？
- [ ] 各页面模块是否可独立增减，无强耦合关系？
- [ ] 品牌色是否已作为首选的个性化手段？

### 生命周期维度
- [ ] 当前设计面向的是哪个用户阶段（潜在 / 活跃 / 忠诚 / 流失）？
- [ ] 是否为不同阶段用户展示了差异化的核心信息（而非同一套页面）？
- [ ] 到期用户是否展示了历史节省金额（而非重新推销）？

### 券包/权益维度
- [ ] 券包是否以「使用端 + 场景」双维度归类，而非仅按金额或有效期排序？
- [ ] 用户能否在 3 秒内判断某张券是否在当前场景可用？
