# 渠道会员设计准则 · Channel Membership Design Principles 

> 一套从电商多渠道会员体系实战中提炼的设计方法论，帮助设计师在「标准化效率」与「个性化适配」之间做出有据可依的设计决策。完整设计准则请参考《电商行业渠道会员Design Skill》

---

## 这是什么

这是一个面向 **Claude AI** 的 Skill 文件，同时也是一份独立可用的**电商会员设计参考手册**。

它来源于Zoey Wang在阿里巴巴会员业务中，对餐饮 SaaS 会员产品的系统性设计实践，经过场景抽象与通用化改造后，适用于：

- 电商平台的会员体系设计
- 品牌自营会员中心的体验规划
- SaaS 商家工具的会员功能设计
- 跨渠道（App / 小程序 / H5 / PC）的会员触点规范制定

无论你是**产品设计师**、**增长设计师**，还是**产品经理**，都可以将这套准则作为设计评审、方案自查、团队对齐的参考框架。

---

## 为什么需要这套准则

会员设计看起来千篇一律，实际上面临三重复合挑战：

```
行业维度  →  同一用户在浏览、决策、结算、售后等场景的心智完全不同
商家维度  →  不同品牌、不同阶段的商家，运营诉求高度个性化
用户维度  →  潜在用户、新用户、忠诚用户、流失用户，每个阶段的设计目标截然不同
```

**平台化的单一解决方案在这里失效。** 这套准则的价值，正是为这三重变量提供一套可操作的设计决策框架。

## 核心内容速览

### 准则一：多场景差异化认知设计

任何会员设计动手之前，先用四维框架评估目标场景：

| 维度 | 评估问题 |
|------|---------|
| 空间可用性 | 这个场景能容纳多少信息？ |
| 基础品牌感 | 该场景本身的品牌承载力有多强？ |
| 信息复杂度 | 用户当前能接受多少信息量？ |
| 场景相关性 | 会员权益与用户当前任务有多相关？ |

三类场景的核心设计原则：

- **浏览场景**：最小化干扰，让价差本身说话，禁止弹出完整会员介绍
- **决策场景**：聚焦本单直接获益，配合单步入会行动点
- **结算场景**：零摩擦入会，原地完成，禁止跳转至会员详情页

---

### 准则二：触点类型化与转化路径

将所有会员曝光入口归为 4 种类型，每种类型有独立的引导策略：

```
A. 任务增益型  →  嵌入用户当前任务流，极简信息（1~2 个点）
B. 决策刺激型  →  放大会员 vs 非会员差异，中等信息量（3~5 个点）
C. 入口分发型  →  全貌展示会员体系，丰富信息（完整权益列表）
D. 直接消费型  →  价格标签本身即引导，无需额外话术
```

入会链路三段责任制：

```
购前（曝光转化）  →  产生了解动机         关键指标：曝光点击率
购中（入会转化）  →  降低填写摩擦         关键指标：入会完成率
购后（使用转化）  →  首次感知权益价值      关键指标：首次权益使用率
```

---

### 准则三：半开放式个性化框架

面对高度分散的商家类型，采用三层嵌套框架平衡标准化与个性化：

```
┌──────────────────────────────┐
│  样式定制层（优先开放）        │  品牌色、卡面图案 → 最小成本，最大品牌感知
├──────────────────────────────┤
│  内容灵活层（可配置）          │  模块零耦合，可独立增减组合
├──────────────────────────────┤
│  链路统一层（不可定制）        │  注册/入会/领取/使用流程，所有商家共用
└──────────────────────────────┘
```

**核心结论**：品牌色是性价比最高的个性化手段——仅替换主色，即可显著改变整体品牌感知，无需改动结构。

---

### 准则四：用户生命周期阶段化设计

三个阶段，三种核心心理，三套设计策略：

| 阶段 | 核心心理 | 设计关键词 |
|------|---------|-----------|
| 潜在用户 | 价值可兑现预期 | 直观、立享、品牌快速认知 |
| 活跃用户 | 价值已兑现印证 | 既得权益、沉没成本、成长进度 |
| 忠诚用户 | 身份对比度与优越感 | 尊贵感、个性化、身份标识 |

**流失/到期用户的关键原则**：不要把到期用户当新用户重新说服。正确做法是展示「上期已为你节省 ¥XX」，激活沉没成本感知，而非重复权益介绍。

**入会引导页的页面框架**（针对潜在用户）：

```
头部  →  心智对焦，强化适用范围的广泛性，建立信任
颈部  →  权益符号化聚合，让用户快速感知多样性（≥3 种权益转化率显著提升）
身部  →  按权益类型敏感度排序，放大数量敏感型权益的曝光空间
```

### 附：设计决策 Checklist

在提交任何会员相关设计方案前，可用以下 Checklist 自查：

**场景维度**
- [ ] 是否识别了该入口的触点类型？
- [ ] 信息量级是否与场景的"空间可用性 × 场景相关性"匹配？
- [ ] 结算场景是否避免了跳转至会员详情页？

**转化维度**
- [ ] 入会引导是否清晰呈现了"立即可得"的权益？
- [ ] 是否利用了渠道账号能力减少手动填写？
- [ ] 权益展示是否包含至少 3 种不同类型？

**个性化框架维度**
- [ ] 商家定制是否仅在样式层和内容层，未破坏链路层统一性？
- [ ] 各模块是否可独立增减、无强耦合？

**生命周期维度**
- [ ] 当前设计明确面向哪个用户阶段？
- [ ] 不同阶段用户是否展示了差异化的核心信息？
- [ ] 到期用户是否展示了历史节省金额而非重新推销？

**券包维度**
- [ ] 券包是否以「使用端 + 场景」双维度归类？
- [ ] 用户能否在 3 秒内判断某张券在当前场景是否可用？

## 如何使用

### 作为 Claude Skill 使用

将 `SKILL.md` 安装为 Claude 的自定义 Skill，Claude 在涉及会员设计、权益展示、用户转化路径等相关讨论时会自动参考这套准则，输出有结构、有依据的设计建议。

### 作为设计参考手册使用

直接阅读 `SKILL.md` 的完整内容，在项目启动、方案评审、团队对齐时作为参考框架。Checklist 部分可直接复制到 Notion、飞书文档中使用。

### 作为团队设计规范的起点

这套准则是通用抽象层，建议在此基础上叠加你的产品具体场景、品牌规范和业务数据，形成团队专属的会员设计规范。
