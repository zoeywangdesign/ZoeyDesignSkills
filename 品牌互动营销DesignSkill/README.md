# 品牌互动营销 DesignSkill

这个文件夹沉淀的是一套用于**电商品牌互动营销设计**的方法型 Skill。  
它不是某个单独项目的复盘，也不是某种固定活动模板，而是一套从品牌互动营销实践中抽离出来的**通用设计准则**与**设计框架**。

## 这个 Skill 解决什么问题

它主要解决以下问题：

1. 如何把“活动设计经验”升级成“系统设计方法”
2. 如何从具体品牌项目中抽离出通用设计原则
3. 如何让互动营销产品同时兼顾品牌表达、用户体验与转化效率
4. 如何建立适用于高频营销需求的组件化、标准化设计框架
5. 如何把营销页面设计从一次性方案变成可复用能力

---

## 核心思想

这套 Skill 的核心观点是：

> 品牌互动营销不是单次活动页，而是持续经营用户关系的交互系统。

因此，它强调：

- 以用户关系阶段为基础的设计分层
- 以转化链路为核心的结构设计
- 以品牌目标与用户目标并重的产品定义
- 以组件化、一致性、可复用为基础的系统能力建设
- 以数据验证设计有效性

## 使用方式建议

你可以把这个 Skill 用在以下工作流里：

### 用法 1：做新方案前
先用文档里的“通用设计准则”和“判断清单”审视需求，明确：

- 是在解决拉新、激活、转化还是留存问题
- 当前目标用户处于哪个关系阶段
- 页面究竟要推动什么行为发生

### 用法 2：评估现有方案
用文档中的设计原则反向检查：

- 页面是否只重视觉不重转化
- 信息是否不够结构化
- 操作流程是否不够短
- 品牌表达是否干扰可用性
- 是否缺乏状态系统和反馈机制

### 用法 3：沉淀团队规范
可将其中内容拆解为：

- 设计原则页
- 营销产品设计 checklist
- 组件建设方向
- 设计评审标准
- 数据复盘指标框架

## 一句话总结

如果说普通活动页设计关注的是“做出一个页面”，  
那么这个 Skill 关注的是：

**如何为品牌持续经营用户关系，设计一套可转化、可复用、可验证的互动营销产品方法。**
