# 电商行业商家会员全生命周期 Design Skill

一份面向电商行业的会员设计方法总结，聚焦“店铺/商家会员”的全生命周期设计，帮助设计师、产品经理、运营同学从分散需求中抽离出可复用、可迁移、可系统化的方法论。

## 项目简介

该文档将电商商家会员体系中常见的设计问题进行抽象与结构化整理，覆盖会员从认知建立、身份塑造、权益表达，到入会转化、留存复购、续费挽留、流失召回等关键阶段，适合作为：

- 电商会员体系设计参考
- 店铺会员设计复盘沉淀
- 团队内部设计规范与知识库
- 新成员学习会员设计的入门资料
- 会员项目立项前的方法框架参考

## 适用对象

- 电商产品设计师
- 用户体验设计师
- 产品经理
- 商家运营/会员运营
- 需要系统理解店铺会员设计的人

## 文档特点

- 去平台化：不绑定具体平台
- 去商家化：不依赖具体品牌或商家案例
- 去数据化：不包含特定业务数据结论
- 可复用：强调通用设计原则与方法
- 可落地：包含框架、准则、分类与检查清单

## 核心内容

本 Skill 主要包含以下内容：

- 店铺会员设计的目标与边界
- 常见问题拆解
- 系统化设计原则
- 会员认知、身份、权益、转化、运营的结构框架
- 生命周期设计准则
- 多触点一致性设计方法
- 权益分类参考
- 设计检查清单
- 常见误区总结

## 使用方式

你可以将这份文档用于以下场景：

1. 在新项目启动前，快速建立会员设计的全局框架  
2. 在需求评审中，辅助判断当前设计解决的是哪一类会员问题  
3. 在设计过程中，作为信息架构与触点规划的参考  
4. 在复盘阶段，作为设计策略抽象与沉淀模板  
5. 在团队知识库中，作为通用会员设计 Skill 进行共享
