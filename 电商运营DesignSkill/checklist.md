# Checklist：电商用户全生命周期运营 Design Skill

## 一、生命周期视角
- [ ] 是否明确用户处于哪个生命周期阶段？
- [ ] 是否定义了希望推动的用户迁移？
- [ ] 是否避免只讨论单次成交或单次活动？
- [ ] 是否体现出阶段递进关系？

## 二、用户分层
- [ ] 是否对用户做了有效分层？
- [ ] 分层是否服务于策略分配，而不只是标签展示？
- [ ] 不同分层是否对应不同目标和动作？
- [ ] 是否区分了高价值用户与高潜力用户？

## 三、认知与价值表达
- [ ] 是否定义了清晰的核心价值主张？
- [ ] 是否降低了用户理解成本？
- [ ] 是否做到多触点表达一致？
- [ ] 是否同时覆盖理性价值与感性识别？

## 四、链路协同
- [ ] 是否覆盖触达、理解、决策、转化、留存、复购等关键环节？
- [ ] 每个触点是否有清晰职责？
- [ ] 前后链路是否信息一致、逐层递进？
- [ ] 是否明确了每个节点的下一步行动？

## 五、内容 / 供给 / 权益
- [ ] 内容是否围绕用户决策问题组织？
- [ ] 供给是否匹配不同生命周期阶段？
- [ ] 权益是否服务于降低门槛和推动迁移？
- [ ] 是否避免长期只依赖价格刺激？
- [ ] 内容、供给、权益三者是否协同？

## 六、体验与转化
- [ ] 是否降低了关键路径中的行动摩擦？
- [ ] 是否在关键节点提供了足够的信任证明？
- [ ] 是否让关键动作更直观、更低负担？
- [ ] 是否兼顾了首次转化与持续使用？

## 七、渠道协同
- [ ] 是否定义了多渠道的分工关系？
- [ ] 是否保证不同渠道的价值表达一致？
- [ ] 是否避免渠道各自为战？
- [ ] 是否实现引导、承接、转化、回流协同？

## 八、数据与反馈
- [ ] 是否定义了阶段性成功指标？
- [ ] 指标是否围绕用户迁移而不是孤立行为？
- [ ] 是否建立了反馈闭环？
- [ ] 数据结果是否能映射到具体策略调整？

## 九、方法论质量
- [ ] 输出是否去平台化、去场景化？
- [ ] 输出是否避免沦为战术清单？
- [ ] 输出是否具备可复用性？
- [ ] 输出是否适合作为团队共识文档或知识库条目？

## 十、最终判定
如果以下四项都满足，则基本可以认为方案合格：
- [ ] 有生命周期主轴
- [ ] 有用户迁移逻辑
- [ ] 有链路与供给协同
- [ ] 有数据闭环与迭代机制
