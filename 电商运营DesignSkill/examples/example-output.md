# Example Output：期望输出示例

## 一句话总结
电商用户全生命周期运营设计，应围绕用户关系演进，系统设计认知、分层、链路、供给、权益与反馈机制，持续推动用户向更高价值阶段迁移。

## 核心框架
1. 生命周期分阶段
2. 用户迁移目标定义
3. 分层策略设计
4. 全链路触点协同
5. 内容/供给/权益协同
6. 数据反馈闭环

## 示例准则
- 以生命周期阶段而非单次交易作为运营基本单位
- 以用户迁移而非单次成交作为核心目标
- 先建立认知，再推动行动
- 分层必须服务于策略分配
- 每个触点都应有明确职责
- 权益用于降低门槛和加速推进，而非替代长期价值
- 指标应围绕阶段跃迁而非孤立行为

## 适合作为 Design Skill 的输出形式
- 方法论文档
- 评审清单
- Prompt模板
- 表格模板
- 团队规范
