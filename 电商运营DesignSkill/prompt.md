# Prompt Pack：电商用户全生命周期运营 Design Skill

## Prompt 1：从材料中提炼通用设计准则
请从以下材料中，提取其中关于“电商用户全生命周期运营”的通用设计准则。要求：

- 去平台化：不要保留任何具体平台名
- 去场景化：不要保留任何特定活动、频道、页面、品类场景
- 去战术化：不要停留在单次活动打法
- 保留系统性：输出必须能体现生命周期、用户迁移、分层策略、链路协同、供给/内容/权益协同、数据闭环
- 输出要适合写入方法论文档，可被团队复用

请按以下结构输出：
1. 一句话方法论总结
2. 生命周期总纲
3. 通用设计准则
4. 生命周期阶段与对应设计重点
5. 常见误区
6. 适合落地的检查清单

## Prompt 3：评审一份运营方案是否系统完整
请使用“电商用户全生命周期运营 Design Skill”的标准，评审以下方案是否系统完整。

请重点检查：
- 是否具备生命周期视角
- 是否定义了用户迁移目标
- 是否有明确分层策略
- 是否打通了链路协同
- 是否实现了内容/供给/权益协同

输出格式：
1. 总体评价
2. 优点
3. 缺失项
4. 风险点
