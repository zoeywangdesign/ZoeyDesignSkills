# SKILL CARD：电商用户全生命周期运营 Design Skill

## 1. 基本信息

- **Skill名称**：电商用户全生命周期运营 Design Skill
- **英文名**：E-commerce User Lifecycle Operations Design Skill
- **版本**：1.0
- **类型**：Strategy / Operations Design / Design Skill
- **语言**：中文
- **状态**：Ready to Use

---

## 2. 一句话定义

将具体、零散、场景化的电商运营材料，抽象为系统化、可复用的用户全生命周期运营设计框架。

---

## 3. 适用场景

本 Skill 适用于：

- 从运营方案中提炼通用方法论
- 将零散运营动作整理成体系
- 评审用户运营方案是否系统完整
- 沉淀团队统一的运营设计原则
- 构建跨策略、产品、设计、运营协作的分析语言

---

## 4. 不适用场景

本 Skill 不适用于：

- 输出具体平台后台操作步骤
- 生成某一次营销活动的执行排期
- 写单渠道投放文案
- 提供高度业务绑定的 SOP
- 替代具体行业经营经验本身

---

## 5. 核心输入

可接受的输入包括：

- PPT / PDF / 方案文档
- 页面说明 / 触点说明 / 流程图
- 用户分层策略
- 增长、激活、留存、复购目标
- 一段简单的需求描述

---

## 6. 核心输出

本 Skill 最常见输出包括：

- 生命周期框架
- 用户迁移逻辑
- 通用设计准则
- 分层策略模型
- 链路职责拆解
- 内容 / 供给 / 权益协同原则
- 数据反馈闭环
- 评审清单
- Prompt 模板
- Skill / 方法论文档

---

## 7. 核心方法

默认采用以下分析路径：

1. 判断生命周期阶段
2. 识别用户迁移目标
3. 拆解用户 / 触点 / 内容 / 供给权益 / 数据
4. 去平台化与去场景化
5. 重组为结构化框架
6. 输出原则、模板或评审报告

---

## 8. 最关键的判断标准

一个合格输出，至少要满足：

- 有生命周期主轴
- 有用户迁移逻辑
- 有分层运营思维
- 有链路协同关系
- 有内容/供给/权益协同
- 有数据反馈闭环
- 可被复用，而不是仅服务一次任务

---

## 9. 常用输出形态

### 形态 A：原则文档
适合沉淀方法论、做团队培训、入知识库。

### 形态 B：结构化框架
适合整理零散内容、提炼运营骨架。

### 形态 C：评审报告
适合方案诊断、发现缺口、提出优化建议。

### 形态 D：Skill 包
适合长期复用、给 AI / 团队反复调用。

---

## 10. 典型任务指令

### 指令 1
请从以下材料中提炼电商用户全生命周期运营的通用设计原则，要求去平台化、去场景化、去活动化。

### 指令 2
请将以下零散运营动作整理为“生命周期阶段—用户迁移—链路职责—内容/供给/权益策略—反馈机制”的结构化框架。

### 指令 3
请使用本 Skill 的标准，评审这份方案是否具备系统化运营设计能力，并指出缺失项和优化建议。

### 指令 4
请将以下材料沉淀为一份可直接进入团队知识库的 Design Skill 文档。
